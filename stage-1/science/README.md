# Science track

The science track is a separate set of 14 units that runs alongside the modules. You do not read it front to back before you bake. Each unit is read **the first time its phenomenon shows up on the bench**: the lesson that needs it links to it in its prerequisite box, and the unit links back to every lesson and experiment that uses it.

The goal is the one in the course brief: *I understand enough science that I can predict what will happen when I change an ingredient or process.* This is not a university course. Each unit gives you a correct mental model, the handful of numbers worth remembering (temperatures, ranges, ratios) and an intuitive mechanism, then turns it straight into bench predictions you can test.

## How a unit is built

| Section | What it gives you |
|---|---|
| The one-paragraph model | The whole idea in plain language: read this first, and again before a bake |
| The mechanism | How it works, with tables of key numbers and ranges |
| What it predicts on the bench | *If you change X → prediction → why → where you'll see it*, linked to lessons and experiments |
| Kitchen demonstrations | 1–3 tiny demos with household items to see the effect yourself |
| Misconceptions | The common wrong models, corrected |
| Measuring it | Which instrument answers which question, and whether it is Stage 1, 2 or 3 equipment |
| Check yourself | Prediction questions with hidden answers |
| Going deeper | The concrete Stage 2/3 extension of the unit |

## The four branches

| Branch | Units | What it explains |
|---|---|---|
| Chemistry | SC-01 to SC-07, SC-13 | The ingredients as molecules: water, sugars and starch, proteins, fats, acids and bases, colloids, browning, crystallization |
| Biology | SC-08, SC-09 | Living and biological agents: yeast, bacteria, food safety, enzymes |
| Physics | SC-10 to SC-12 | Heat, steam, gas expansion and how doughs flow and stretch |
| Measurement | SC-14 | How to measure, taste and compare reliably, and how much variation to expect |

## Suggested reading order

**Default: read each unit when its first lesson asks for it.** Following the modules, that gives this order:

| Order | Unit | Read before |
|---|---|---|
| 1 | SC-10 Heat transfer | 00.2 |
| 2 | SC-08 Microbiology | 00.3 |
| 3 | SC-01 Water | 01.2 |
| 4 | SC-02 Carbohydrates | 02.1 |
| 5 | SC-03 Proteins | 02.1 |
| 6 | SC-12 Rheology | 02.2 |
| 7 | SC-09 Enzymes | 03.1 |
| 8 | SC-11 Phase changes and gases | 04.1 |
| 9 | SC-07 Browning | 04.2 |
| 10 | SC-05 Acids, bases and pH | 05.3 |
| 11 | SC-04 Lipids | 06.1 |
| 12 | SC-13 Crystallization | 07.2 |
| 13 | SC-06 Colloids | 09.2 |
| 14 | SC-14 Measurement and sensory | 18.2 |

You do not need every section on first read. On first contact read the one-paragraph model, skim the mechanism, and use the prediction table; come back to the full unit when a later lesson links to it again or a bake fails in a way you cannot explain.

**Alternative: a science-first pass.** If you prefer to build the model before touching the bench (or are reviewing before the final exam), read by branch in this order: SC-01 → SC-02 → SC-03 → SC-04 → SC-05 → SC-06 → SC-07 → SC-13 (chemistry builds on itself in this sequence), then SC-08 → SC-09, then SC-10 → SC-11 → SC-12, and SC-14 last. Pair each unit with at least one kitchen demonstration so the numbers attach to something you have seen.
