# Recipe library

Every recipe uses the same standardized format: objective, expected result, formula in grams and baker's percentages, equipment, mise en place, procedure with measurable endpoints, critical control points, common failures, scientific explanation, variables you can change and experiment suggestions ([template](templates/recipe-template.md)).

Each recipe is labelled with its origin: <span class="tag established">Established technique</span> <span class="tag source">Source-derived</span> <span class="tag educational">Educational formulation</span> <span class="tag experimental">Experimental formulation</span>. Mark a recipe complete once you have made it to specification.
