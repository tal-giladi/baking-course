# Essential equipment

Required for Stage 1; "Necessary: yes" means a lesson depends on the measurement or control it provides. Overview and buying order: [Equipment curriculum](equipment/README.md).

## Measurement

### Digital scale, 1 g :id=scale

| | |
|---|---|
| **What it does** | Weighs up to 5 kg at 1 g resolution, with tare. |
| **Why it matters** | Volume measures of flour vary by 20 % or more depending on how the cup is filled ([X1-01](experiments/X1-01-volume-vs-weight.md)). Baker's percentages only work in mass. |
| **Variable controlled** | Ingredient mass, hydration, dough division weight, yield and loss. |
| **Necessary?** | Yes. The course cannot be followed without it. Liquids are weighed too. |
| **Cheaper alternative** | None acceptable. Check it with known masses (a sealed 1 kg bag, coins of published mass) as in [X1-02](experiments/X1-02-calibration.md). |
| **First used in** | [00.2](stage-1/module-00/lesson-02.md) |

### Precision scale, 0.1 g or 0.01 g :id=precision-scale

| | |
|---|---|
| **What it does** | Weighs small quantities (typically up to 100–500 g) at 0.1 g or 0.01 g. |
| **Why it matters** | In a 200 g flour test batch, 1 % instant yeast is 2 g. On a 1 g scale that reading could be anywhere from 1.5 to 2.5 g — a ±25 % error in the variable you are testing. Salt, yeast, leaveners, gelatine and spices all need this resolution. |
| **Variable controlled** | Minor-ingredient dose. |
| **Necessary?** | Yes, because Stage 1 experiments use small batches. |
| **Cheaper alternative** | A "pocket" jewellery-type scale is fine. Otherwise weigh ten times the dose into a larger quantity of flour or water and take a tenth by mass (dilution method, taught in [01.1](stage-1/module-01/lesson-01.md)). |
| **First used in** | [01.1](stage-1/module-01/lesson-01.md) |

### Instant-read probe thermometer :id=probe

| | |
|---|---|
| **What it does** | Reads the core temperature of dough, liquids, custards and baked goods within a few seconds. |
| **Why it matters** | Dough temperature sets fermentation rate; internal temperature tells you when bread is baked (about 96–99 °C for lean loaves), when anglaise has thickened (about 82 °C) and when chocolate is in temper. |
| **Variable controlled** | Water temperature for DDT, dough temperature, product endpoint temperature. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | None; prefer a thin-tip digital probe to a dial. Check it in ice water (0 °C) and boiling water (100 °C at sea level) per [X1-02](experiments/X1-02-calibration.md). |
| **First used in** | [01.3](stage-1/module-01/lesson-03.md) |

### Oven thermometer :id=oven-thermometer

| | |
|---|---|
| **What it does** | Sits on the shelf and shows the actual air temperature where the product is. |
| **Why it matters** | Home ovens commonly run 10–25 °C off their dial and cycle around the set point. Without a reading, bake-time experiments measure your thermostat, not your dough. |
| **Variable controlled** | Baking temperature; lets you build an oven map of hot and cold zones. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | A probe thermometer with an oven-safe cable does both jobs. The sugar-browning test (squares of white bread on each shelf position) maps hot spots without any instrument. |
| **First used in** | [00.2](stage-1/module-00/lesson-02.md) |

### Timer :id=timer

| | |
|---|---|
| **What it does** | Counts time, ideally several events at once. |
| **Why it matters** | Mixing time, bulk fermentation, proof and bake are all recorded variables. "About an hour" cannot be compared between batches. |
| **Variable controlled** | Duration of each process step. |
| **Necessary?** | Yes, in any form. |
| **Cheaper alternative** | A phone with multiple named timers. Write start clock-times in the notebook as a backup. |
| **First used in** | [03.2](stage-1/module-03/lesson-02.md) |

### Ruler and measuring tape :id=ruler

| | |
|---|---|
| **What it does** | Measures dough sheet thickness and size, loaf height, cookie spread and cake rise. |
| **Why it matters** | Turns visual impressions into numbers you can compare: spread in mm, loaf height in cm, rolled thickness to the nearest mm. |
| **Variable controlled** | Dimensions: sheeting thickness, shaping size, product geometry. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | A clean steel ruler is enough. Paired dowels or guide sticks of known thickness under the rolling pin give even sheets. |
| **First used in** | [03.4](stage-1/module-03/lesson-04.md) |

### Lab notebook :id=notebook

| | |
|---|---|
| **What it does** | Records formula, conditions, observations and outcomes for every bake. |
| **Why it matters** | Without records there is no experiment, only anecdote. |
| **Variable controlled** | None directly — it makes every other variable visible. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | A spreadsheet or plain text file. Keep one format and date every entry. |
| **First used in** | [00.1](stage-1/module-00/lesson-01.md) |

## Preparation and mixing

### Mixing bowls and straight-sided dough container :id=bowls

| | |
|---|---|
| **What it does** | Bowls (at least one large, two or three medium, some small for mise en place); a clear, straight-sided container with volume marks for bulk fermentation. |
| **Why it matters** | Straight sides let you read volume increase directly (e.g. 1 L of dough rising to 1.75 L = 75 % increase). In a sloped bowl you guess. |
| **Variable controlled** | Fermentation endpoint by volume; mise en place organisation. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Any clear food-grade tub or large jar; mark the starting level with tape and calibrate by pouring in measured water (1 g water ≈ 1 mL). |
| **First used in** | [02.2](stage-1/module-02/lesson-02.md) |

### Bench scraper and bowl scraper :id=scrapers

| | |
|---|---|
| **What it does** | A rigid scraper divides dough and cleans the bench; a flexible one empties bowls completely. |
| **Why it matters** | Handles wet dough without adding flour, which would change hydration. Complete bowl scraping reduces loss and keeps yields accurate. |
| **Variable controlled** | Division accuracy, bench flour added, process loss. |
| **Necessary?** | Yes; they cost very little. |
| **Cheaper alternative** | A cut piece of rigid plastic lid for the bowl; a wide spatula for the bench. |
| **First used in** | [02.2](stage-1/module-02/lesson-02.md) |

### Rolling pin :id=rolling-pin

| | |
|---|---|
| **What it does** | Sheets dough to an even thickness. |
| **Why it matters** | Thickness decides bake time for pita and cookies, shrinkage in tarts, and layer integrity in lamination. |
| **Variable controlled** | Sheet thickness and uniformity. |
| **Necessary?** | Yes. A straight, handle-less pin gives the most even pressure. |
| **Cheaper alternative** | A smooth wine bottle for occasional use; add guide sticks for thickness. |
| **First used in** | [04.1](stage-1/module-04/lesson-01.md) |

### Whisk and silicone spatula :id=whisk-spatula

| | |
|---|---|
| **What it does** | The balloon whisk incorporates air and disperses; the heat-resistant spatula folds, scrapes and stirs hot mixtures. |
| **Why it matters** | Foam volume depends on how air is introduced; custards scorch where a spoon cannot reach the pan corner. |
| **Variable controlled** | Aeration, shear, uniform heating while stirring. |
| **Necessary?** | Yes. Choose a spatula rated to at least 200 °C for caramel. |
| **Cheaper alternative** | A fork aerates small quantities; a wooden spoon stirs but does not scrape corners. |
| **First used in** | [07.2](stage-1/module-07/lesson-02.md) |

### Heavy-bottomed saucepans :id=saucepans

| | |
|---|---|
| **What it does** | Heats caramel, syrups, custards, choux panade and ganache cream. A small (1–1.5 L) and a medium (2–3 L) pan cover Stage 1. |
| **Why it matters** | A thick base spreads heat, avoiding the local hot spots that scorch milk, burn caramel or curdle custard. Light-coloured interiors let you judge caramel colour. |
| **Variable controlled** | Rate and evenness of heating. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | A thin pan over a heat-diffusing plate, lower heat and more stirring; a bain-marie (bowl over simmering water) for custards and chocolate. |
| **First used in** | [07.2](stage-1/module-07/lesson-02.md) |

### Fine sieve :id=sieve

| | |
|---|---|
| **What it does** | Aerates and de-lumps dry ingredients; strains custards and purées. |
| **Why it matters** | Dispersed leavener and cocoa avoid spots; straining removes coagulated egg from creams. |
| **Variable controlled** | Dispersion and smoothness. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Whisking dry ingredients together de-lumps adequately for muffins; a clean cloth over a colander strains liquids. |
| **First used in** | [08.3](stage-1/module-08/lesson-03.md) |

### Piping bags and a few tips :id=piping

| | |
|---|---|
| **What it does** | Deposits batters and creams at controlled size and shape. A 10–12 mm plain tip, a medium star tip and a small plain tip cover Stage 1. |
| **Why it matters** | Choux and meringue size and profile decide how they rise and bake. |
| **Variable controlled** | Deposit mass, diameter and shape. |
| **Necessary?** | Yes from M13. Disposable bags are fine. |
| **Cheaper alternative** | A heavy zip-top bag with a corner cut, for plain shapes. |
| **First used in** | [13.2](stage-1/module-13/lesson-02.md) |

### Cling film and lidded containers :id=containers

| | |
|---|---|
| **What it does** | Covers dough and stores components. |
| **Why it matters** | An uncovered dough loses moisture and skins over; creams take on fridge odours; pastry cream must be film-contacted to avoid a skin. |
| **Variable controlled** | Surface moisture loss and contamination during rest and storage. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Reusable lidded tubs, shower caps over bowls, damp (not wet) cloths for short rests. |
| **First used in** | [02.2](stage-1/module-02/lesson-02.md) |

### Labels and marker :id=labels

| | |
|---|---|
| **What it does** | Marks contents, date, time and batch/variant on everything stored. |
| **Why it matters** | Food safety (first-in, first-out) and experiment integrity. |
| **Variable controlled** | Traceability. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Masking tape and a permanent marker. |
| **First used in** | [00.3](stage-1/module-00/lesson-03.md) |

## Baking and cooling

### Sheet pans and parchment :id=sheet-pans

| | |
|---|---|
| **What it does** | Flat, rimmed metal pans (at least two that fit your oven) lined with baking paper. |
| **Why it matters** | Heavy, light-coloured pans brown evenly; thin dark pans overbrown bottoms. Parchment releases without added fat. |
| **Variable controlled** | Bottom heat transfer, spread, release. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Double-stack a thin pan to reduce bottom heat. |
| **First used in** | [03.4](stage-1/module-03/lesson-04.md) |

### Loaf pan :id=loaf-pan

| | |
|---|---|
| **What it does** | Contains pan loaves, pound cake and quick breads. A pan of roughly 22 × 11 cm is standard for a 500–700 g dough. |
| **Why it matters** | Pan volume against dough mass decides final shape and bake time; you will calculate dough mass from pan volume in [01.4](stage-1/module-01/lesson-04.md). |
| **Variable controlled** | Product shape, heat path length, bake time. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | Any oven-safe rectangular dish; measure its volume with water and scale dough to it. |
| **First used in** | [03.4](stage-1/module-03/lesson-04.md) |

### Round cake pans, 20 cm :id=cake-pans

| | |
|---|---|
| **What it does** | Two straight-sided 20 cm pans, at least 5 cm deep, for génoise, chiffon-style layers and layer cakes. |
| **Why it matters** | Stage 1 cake formulas are sized to 20 cm; pan diameter and depth change bake time, doming and doneness. |
| **Variable controlled** | Batter depth and heat path. |
| **Necessary?** | Yes from M10. |
| **Cheaper alternative** | One pan and bake in sequence; or scale the formula by area to a pan you own (area ratio = (d₁/d₂)²). A tube pan is ideal for chiffon but a 20 cm pan works with adjusted timing. |
| **First used in** | [10.3](stage-1/module-10/lesson-03.md) |

### Tart ring or removable-bottom tart pan, 20–22 cm :id=tart-ring

| | |
|---|---|
| **What it does** | Shapes and bakes tart shells that can be released cleanly. |
| **Why it matters** | Straight, clean walls expose shrinkage and slumping — the variables of [X1-32](experiments/X1-32-tart-shrinkage.md). A perforated ring on a perforated mat bakes the most evenly; a fluted removable-bottom pan is fine. |
| **Variable controlled** | Shell geometry, wall thickness, shrinkage observation. |
| **Necessary?** | Yes from M11. |
| **Cheaper alternative** | A pie dish for pie work; a springform ring on a sheet pan for tarts. |
| **First used in** | [11.2](stage-1/module-11/lesson-02.md) |

### Covered cast-iron pot (Dutch oven) or baking stone/steel :id=hearth

| | |
|---|---|
| **What it does** | Supplies stored heat to the base of hearth loaves; the covered pot also traps the loaf's own steam. |
| **Why it matters** | Oven spring and crust depend on a fast heat input and a humid first 15–20 minutes. A domestic oven vents steam; the pot is the most reliable home substitute for a steam-injected deck oven ([X1-10](experiments/X1-10-steam.md)). |
| **Variable controlled** | Bottom heat (conduction), early-bake humidity, crust formation timing. |
| **Necessary?** | Yes — one of the two. The pot is more forgiving for round loaves; a stone or steel handles baguettes, pita and multiple rolls. |
| **Cheaper alternative** | An inverted heavy sheet pan preheated as a "stone"; an oven-safe stainless roasting pan inverted over the loaf as a steam cover. |
| **First used in** | [04.1](stage-1/module-04/lesson-01.md) |

### Wire cooling rack :id=rack

| | |
|---|---|
| **What it does** | Lets air reach all sides of a hot product. |
| **Why it matters** | Hot products keep releasing steam; on a solid surface the base condenses moisture and goes soggy. |
| **Variable controlled** | Cooling rate and moisture escape. |
| **Necessary?** | Yes. |
| **Cheaper alternative** | An oven rack balanced on two cans; the grid from a grill pan. |
| **First used in** | [03.2](stage-1/module-03/lesson-02.md) |
