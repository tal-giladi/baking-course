# Professional equipment

Not needed for Stage 1. Relevant in Stage 2 (professional production, where scale and consistency matter) and Stage 3 (R&D, where numbers must be reproducible by another lab). Each entry names the Stage 1 lesson teaching the **manual equivalent**: same principle, while the machine buys throughput, precision or a standard unit. Overview: [Equipment curriculum](equipment/README.md).

## Stage 2: production equipment

### Deck oven :id=deck-oven

| | |
|---|---|
| **What it does** | Bakes directly on heated stone decks with independent top and bottom heat and injected steam. |
| **Why it matters** | Strong conducted bottom heat and controlled steam give the crust and volume of artisan bread, batch after batch. |
| **Variable controlled** | Top/bottom heat balance, steam volume and timing, venting. |
| **Necessary?** | For bread production, yes. For learning, no. |
| **Cheaper alternative** | Covered pot or stone plus steam tray. |
| **Stage 1 manual equivalent** | [04.1](stage-1/module-04/lesson-01.md) |

### Convection or combi oven with steam :id=combi

| | |
|---|---|
| **What it does** | Fan-forced heat with programmable humidity; combi ovens add steam cooking modes. |
| **Why it matters** | Even colour across full trays of viennoiserie and choux; humidity control for bread and custards. Fan speed can distort light batters. |
| **Variable controlled** | Air velocity, humidity, time-temperature programmes. |
| **Necessary?** | Stage 2 pastry production. |
| **Cheaper alternative** | Home fan setting (reduce set temperature by about 15–20 °C), tray rotation. |
| **Stage 1 manual equivalent** | [14.1](stage-1/module-14/lesson-01.md), [X1-38](experiments/X1-38-choux-oven.md) |

### Retarder-proofer :id=retarder

| | |
|---|---|
| **What it does** | A cabinet that holds dough cold (typically 2–5 °C) overnight, then ramps to proofing temperature and humidity on a timer. |
| **Why it matters** | Decouples mixing from baking, so bread and croissants are ready at opening; improves flavour through slow fermentation. |
| **Variable controlled** | Temperature-humidity-time profile. |
| **Necessary?** | For early-morning production. |
| **Cheaper alternative** | Fridge plus a cooler proofing box. |
| **Stage 1 manual equivalent** | [03.3](stage-1/module-03/lesson-03.md) |

### Spiral mixer :id=spiral

| | |
|---|---|
| **What it does** | Rotating bowl and spiral hook; efficient gluten development with low friction heat. |
| **Why it matters** | Repeatable development of 5–100 kg batches; defined first- and second-speed times. |
| **Variable controlled** | Mixing energy and time. |
| **Necessary?** | For bread production. |
| **Cheaper alternative** | Stand mixer at small scale; hand methods. |
| **Stage 1 manual equivalent** | [02.4](stage-1/module-02/lesson-04.md) |

### Sheeter :id=sheeter

| | |
|---|---|
| **What it does** | Reduces dough thickness between rollers in controlled steps. |
| **Why it matters** | Even laminated layers with minimal warming and tearing — decisive for croissant consistency. |
| **Variable controlled** | Thickness reduction per pass. |
| **Necessary?** | For lamination at production scale. |
| **Cheaper alternative** | Rolling pin, guide sticks, cold marble. |
| **Stage 1 manual equivalent** | [15.2](stage-1/module-15/lesson-02.md) |

### Blast chiller/freezer :id=blast-chiller

| | |
|---|---|
| **What it does** | Pulls products through the danger zone rapidly with high-velocity cold air. |
| **Why it matters** | Food safety for creams and custards; small ice crystals in frozen entremets; sets inserts fast. |
| **Variable controlled** | Cooling and freezing rate. |
| **Necessary?** | For production of creams and frozen desserts. |
| **Cheaper alternative** | Thin layers on cold trays, ice bath, domestic freezer at its coldest setting. |
| **Stage 1 manual equivalent** | [12.2](stage-1/module-12/lesson-02.md) |

### Chocolate tempering machine :id=tempering-machine

| | |
|---|---|
| **What it does** | Melts, cools and holds chocolate at working temperature, often with continuous seeding. |
| **Why it matters** | Holds temper for hours; consistent snap and gloss in bonbons and décor. |
| **Variable controlled** | Chocolate temperature and crystal state over time. |
| **Necessary?** | For chocolate production. |
| **Cheaper alternative** | Seeding in a bowl, probe thermometer, test strip. |
| **Stage 1 manual equivalent** | [16.3](stage-1/module-16/lesson-03.md) |

### Vacuum cutter-mixer :id=cutter-mixer

| | |
|---|---|
| **What it does** | High-speed blade bowl, optionally under vacuum, for pastes, emulsions and fillings. |
| **Why it matters** | Fine, air-free emulsions and nut pastes at volume. |
| **Variable controlled** | Shear, particle size, air content. |
| **Necessary?** | Stage 2 kitchens producing pastes and glazes. |
| **Cheaper alternative** | Immersion blender, food processor. |
| **Stage 1 manual equivalent** | [16.2](stage-1/module-16/lesson-02.md) |

## Stage 3: laboratory instruments

### Laboratory balance :id=lab-balance

| | |
|---|---|
| **What it does** | Weighs to 0.001 g or finer in a draught shield, with calibration certificates. |
| **Why it matters** | Dosing enzymes, hydrocolloids and flavours in small formulation trials; moisture determinations. |
| **Variable controlled** | Micro-ingredient mass. |
| **Necessary?** | Stage 3 formulation work. |
| **Cheaper alternative** | 0.01 g scale plus dilution. |
| **Stage 1 manual equivalent** | [01.1](stage-1/module-01/lesson-01.md) |

### Temperature data loggers :id=data-loggers

| | |
|---|---|
| **What it does** | Records temperature (and sometimes humidity) at intervals, including probes left inside baking products. |
| **Why it matters** | Produces heating and cooling curves, validates proofers, fridges and cooling processes. |
| **Variable controlled** | Documented time-temperature history. |
| **Necessary?** | Stage 2 food-safety records; Stage 3 process studies. Low-cost units are affordable earlier. |
| **Cheaper alternative** | Probe readings logged by hand every few minutes. |
| **Stage 1 manual equivalent** | [X1-11](experiments/X1-11-bake-time.md) |

### Water activity meter :id=aw-meter

| | |
|---|---|
| **What it does** | Measures aw — how available the water in a product is, from 0 to 1. |
| **Why it matters** | Answers "will it go stale, soggy or mouldy?" Moisture migrates from high aw to low aw components (filling to shell), and microbial growth is controlled by aw, not total moisture ([SC-01](stage-1/science/sc-01-water.md)). |
| **Variable controlled** | Shelf-life and component-compatibility design. |
| **Necessary?** | Stage 3 shelf-life and formulation work. |
| **Cheaper alternative** | Commercial lab testing; relative comparisons by weight change. |
| **Stage 1 manual equivalent** | [17.1](stage-1/module-17/lesson-01.md), [X1-43](experiments/X1-43-moisture-migration.md) |

### Moisture analyser :id=moisture-analyser

| | |
|---|---|
| **What it does** | Heats a sample on a balance and reports % moisture lost. |
| **Why it matters** | Real flour and product moisture for true hydration and yield calculations. |
| **Variable controlled** | Moisture content. |
| **Necessary?** | Stage 3. |
| **Cheaper alternative** | Weigh, dry in a low oven to constant mass, weigh again. |
| **Stage 1 manual equivalent** | [01.2](stage-1/module-01/lesson-02.md) |

### Texture analyser :id=texture-analyser

| | |
|---|---|
| **What it does** | Compresses, punctures or snaps a sample and records force against distance. |
| **Why it matters** | Puts numbers on firmness, staling and crispness so formulations can be compared objectively. |
| **Variable controlled** | Measurement of texture (an outcome, not an input). |
| **Necessary?** | Stage 3. |
| **Cheaper alternative** | Slice-compression with a fixed weight and ruler; trained sensory scoring. |
| **Stage 1 manual equivalent** | [X1-12](experiments/X1-12-staling.md), [19.1](stage-1/module-19/lesson-01.md) |

### Colorimeter :id=colorimeter

| | |
|---|---|
| **What it does** | Measures colour as numbers (typically L\*a\*b\*). |
| **Why it matters** | Quantifies crust and caramel browning across trials. |
| **Variable controlled** | Measurement of browning outcome. |
| **Necessary?** | Stage 3. |
| **Cheaper alternative** | Photos under the same light with a grey card and colour reference in frame. |
| **Stage 1 manual equivalent** | [04.2](stage-1/module-04/lesson-02.md) |

### Farinograph, alveograph and lab rheology :id=rheology

| | |
|---|---|
| **What it does** | Standardized tests of flour water absorption, dough development time, stability and extensibility. Usually bought as a service or read from the mill's specification sheet. |
| **Why it matters** | Lets you choose and specify flour by behaviour rather than protein alone. |
| **Variable controlled** | Flour selection and specification. |
| **Necessary?** | Stage 3; learn to read the mill's data sheet in Stage 2. |
| **Cheaper alternative** | Gluten wash, hydration and mixing-time series. |
| **Stage 1 manual equivalent** | [02.4](stage-1/module-02/lesson-04.md), [X1-03](experiments/X1-03-gluten-wash.md) |

### Sensory booth practices :id=sensory

| | |
|---|---|
| **What it does** | Isolated tasting positions, controlled light, coded samples, randomized order. |
| **Why it matters** | Removes bias so "B is softer" is a result, not an opinion. The method matters more than the furniture. |
| **Variable controlled** | Evaluation bias. |
| **Necessary?** | The method is used from Stage 1; dedicated booths are Stage 3. |
| **Cheaper alternative** | Three-digit codes, blind tasting, water between samples, a quiet table. |
| **Stage 1 manual equivalent** | [19.1](stage-1/module-19/lesson-01.md) |
