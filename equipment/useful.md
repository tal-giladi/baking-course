# Useful equipment

These improve experimentation, repeatability or speed; none is required for Stage 1, and each entry names the workaround. Buy one when your notebook shows the manual method is limiting results. Overview: [Equipment curriculum](equipment/README.md).

## Instruments

### Infrared thermometer :id=infrared

| | |
|---|---|
| **What it does** | Reads **surface** temperature without contact. |
| **Why it matters** | Confirms a stone, steel or pan is fully preheated, and checks marble or bench temperature for chocolate and lamination. It cannot read the inside of a dough or liquid, and shiny metal reads falsely low. |
| **Variable controlled** | Surface temperature of hearth and work surfaces. |
| **Necessary?** | No. |
| **Cheaper alternative** | Preheat stones and steels for a fixed 45–60 min after the oven reaches temperature; use the probe for everything internal. |
| **First used in** | [04.1](stage-1/module-04/lesson-01.md) |

### pH meter or pH strips :id=ph

| | |
|---|---|
| **What it does** | Measures acidity. A meter needs two-point calibration with pH 4.01 and 7.00 buffers before each session and a food-grade (spear) electrode stored wet. Strips give a band of about ±0.5 pH. |
| **Why it matters** | Answers "how far has acidification gone?" in levain and sourdough (a ripe levain commonly sits around pH 3.8–4.2) and explains why acid changes gluten and browning. |
| **Variable controlled** | Levain maturity and feeding schedule; tracking in [X1-14](experiments/X1-14-levain.md). |
| **Necessary?** | No. Strips are enough to see the trend. |
| **Cheaper alternative** | Narrow-range strips (e.g. 3.0–5.5); rise height and aroma logged against time. |
| **First used in** | [05.3](stage-1/module-05/lesson-03.md) |

### Refractometer (°Brix) :id=refractometer

| | |
|---|---|
| **What it does** | Measures dissolved solids as °Brix (grams of sucrose-equivalent per 100 g solution) from one drop. Choose automatic temperature compensation and a 0–90 °Brix range, or two ranges. |
| **Why it matters** | Answers "how concentrated is this syrup, glaze or fruit filling?" — which predicts sweetness, set, crystallization risk and microbial stability. Readings are sucrose-equivalent; other solutes read approximately. |
| **Variable controlled** | Syrup concentration, soaking-syrup strength, fruit ripeness/sugar. |
| **Necessary?** | No. |
| **Cheaper alternative** | Weigh sugar and water and calculate concentration; weigh the pan before and after boiling to compute water lost. |
| **First used in** | [13.1](stage-1/module-13/lesson-01.md) |

### Sugar/candy thermometer :id=sugar-thermometer

| | |
|---|---|
| **What it does** | Clips to the pan and reads boiling syrup up to about 200 °C (390 °F). |
| **Why it matters** | Boiling point rises as water leaves, so temperature is a proxy for concentration: 118–121 °C (244–250 °F) for Italian meringue syrup, higher for caramel. Hands-free reading while you pour or whisk. |
| **Variable controlled** | Syrup stage. |
| **Necessary?** | No, if your probe thermometer reads to 200 °C. |
| **Cheaper alternative** | Your probe thermometer, held off the pan base; cold-water ball tests as a cross-check. |
| **First used in** | [07.2](stage-1/module-07/lesson-02.md) |

### Fridge/freezer thermometer :id=fridge-thermometer

| | |
|---|---|
| **What it does** | Shows the actual temperature inside the fridge or freezer. |
| **Why it matters** | Retarding and cold bulk rely on a known temperature (3–5 °C behaves very differently from 8 °C); food safety needs ≤5 °C. |
| **Variable controlled** | Cold-storage temperature. |
| **Necessary?** | No, but low-cost and recommended. |
| **Cheaper alternative** | A glass of water left overnight, then read with the probe. |
| **First used in** | [00.3](stage-1/module-00/lesson-03.md) |

### Digital calipers :id=calipers

| | |
|---|---|
| **What it does** | Measures thickness to 0.1 mm. |
| **Why it matters** | Answers "is my sheet even?" for tart dough and laminated dough, and measures crust thickness, cookie height and layer counts on a cut cross-section. |
| **Variable controlled** | Sheet and product thickness. |
| **Necessary?** | No. |
| **Cheaper alternative** | Ruler plus guide sticks. |
| **First used in** | [11.2](stage-1/module-11/lesson-02.md) |

## Fermentation and bread

### Proofing box or DIY cooler proofing setup :id=proofing-box

| | |
|---|---|
| **What it does** | Holds dough at a set temperature (typically 24–28 °C for proof). |
| **Why it matters** | A fixed temperature makes fermentation times comparable between days ([X1-07](experiments/X1-07-fermentation-temperature.md)). |
| **Variable controlled** | Fermentation temperature. |
| **Necessary?** | No. |
| **Cheaper alternative** | An insulated cooler with a jar of warm water, topped up to hold temperature; an oven with only the light on (check with a thermometer — it can exceed 30 °C). |
| **First used in** | [03.3](stage-1/module-03/lesson-03.md) |

### Banneton and couche :id=banneton

| | |
|---|---|
| **What it does** | A banneton supports a round or oval loaf during final proof; a heavy linen couche supports baguettes and batards in pleats. |
| **Why it matters** | Support lets high-hydration dough proof without spreading and forms a dry skin that scores cleanly. |
| **Variable controlled** | Loaf shape and surface skin during proof. |
| **Necessary?** | No. |
| **Cheaper alternative** | A bowl or colander lined with a well-floured linen tea towel (rice flour sticks least). |
| **First used in** | [03.4](stage-1/module-03/lesson-04.md) |

### Lame :id=lame

| | |
|---|---|
| **What it does** | Holds a razor blade for scoring. |
| **Why it matters** | A clean, shallow, angled cut controls where the loaf opens and how the ear forms. |
| **Variable controlled** | Expansion direction, score depth and angle. |
| **Necessary?** | No. |
| **Cheaper alternative** | A double-edged razor blade on a coffee stirrer; a very sharp serrated knife. |
| **First used in** | [03.4](stage-1/module-03/lesson-04.md) |

### Baking steel :id=steel

| | |
|---|---|
| **What it does** | A thick steel plate that stores and conducts heat faster than ceramic stone. |
| **Why it matters** | Higher bottom heat flux: better pita pockets, stronger oven spring for flat loaves. Can scorch enriched doughs. |
| **Variable controlled** | Bottom heat input. |
| **Necessary?** | No — the Essential pot or stone suffices. |
| **Cheaper alternative** | Stone, or a preheated inverted heavy pan. |
| **First used in** | [04.1](stage-1/module-04/lesson-01.md) |

## Mixing and processing

### Stand mixer :id=stand-mixer

| | |
|---|---|
| **What it does** | Mixes, kneads and whips with consistent speed and time. |
| **Why it matters** | Brioche with 40–60 % butter and meringue buttercreams are hard by hand; repeatable mix time makes gluten experiments cleaner. |
| **Variable controlled** | Mixing intensity and time; whipping rate. |
| **Necessary?** | No. Every Stage 1 recipe has a hand method, with longer times. |
| **Cheaper alternative** | Hand mixing with slap-and-fold; an electric hand mixer for foams and creaming. |
| **First used in** | [06.4](stage-1/module-06/lesson-04.md) |

### Immersion (hand) blender :id=immersion-blender

| | |
|---|---|
| **What it does** | High-shear blending in a narrow container. |
| **Why it matters** | Makes finer, more stable emulsions — ganache, mayonnaise, glazes — with less incorporated air than a whisk. |
| **Variable controlled** | Droplet size (emulsion fineness), air inclusion. |
| **Necessary?** | No. |
| **Cheaper alternative** | Whisk steadily, adding liquid gradually; strain afterwards. |
| **First used in** | [09.3](stage-1/module-09/lesson-03.md) |

### Food processor :id=food-processor

| | |
|---|---|
| **What it does** | Cuts fat into flour, grinds nuts, blends pastes. |
| **Why it matters** | Fast cutting keeps butter cold for brisée and pie dough; fine nut flour for crème d'amande. |
| **Variable controlled** | Fat piece size, particle size. |
| **Necessary?** | No. Hand rubbing-in is taught first because it shows you the fat state. |
| **Cheaper alternative** | Pastry cutter or fingertips; box grater for frozen butter. |
| **First used in** | [11.1](stage-1/module-11/lesson-01.md) |

### Microplane :id=microplane

| | |
|---|---|
| **What it does** | Removes citrus zest without pith; grates nutmeg and chocolate finely. |
| **Why it matters** | Zest carries the aromatic oils; pith adds bitterness. |
| **Variable controlled** | Flavour extraction. |
| **Necessary?** | No. |
| **Cheaper alternative** | Fine side of a box grater. |
| **First used in** | [08.3](stage-1/module-08/lesson-03.md) |

## Pastry work and finishing

### Silicone baking mat :id=silicone-mat

| | |
|---|---|
| **What it does** | Reusable non-stick liner; perforated versions let moisture escape under tart shells. |
| **Why it matters** | Insulates the base slightly, so cookies spread and brown differently from parchment — record which you used. |
| **Variable controlled** | Bottom heat and release. |
| **Necessary?** | No. |
| **Cheaper alternative** | Parchment. |
| **First used in** | [07.3](stage-1/module-07/lesson-03.md) |

### Dough docker :id=docker

| | |
|---|---|
| **What it does** | Pricks many small holes in rolled dough. |
| **Why it matters** | Lets steam escape so tart bases and puff sheets bake flat. |
| **Variable controlled** | Base lift and blistering. |
| **Necessary?** | No. |
| **Cheaper alternative** | A fork. |
| **First used in** | [11.2](stage-1/module-11/lesson-02.md) |

### Bench brush :id=bench-brush

| | |
|---|---|
| **What it does** | Removes excess dusting flour. |
| **Why it matters** | Flour trapped between laminated layers glues them and reduces lift; excess flour on shells toughens and dries them. |
| **Variable controlled** | Surface flour between layers. |
| **Necessary?** | No. |
| **Cheaper alternative** | A clean, dry pastry brush. |
| **First used in** | [15.2](stage-1/module-15/lesson-02.md) |

### Offset spatulas :id=offset

| | |
|---|---|
| **What it does** | Spreads batters level and finishes creams; small and large sizes. |
| **Why it matters** | Even batter depth means even baking; clean finishing of layers. |
| **Variable controlled** | Layer evenness. |
| **Necessary?** | No, but they are inexpensive and used constantly. |
| **Cheaper alternative** | A flat table knife; the back of a spoon. |
| **First used in** | [10.4](stage-1/module-10/lesson-04.md) |

### Cake turntable :id=turntable

| | |
|---|---|
| **What it does** | Rotates a cake while you frost or pipe. |
| **Why it matters** | Speed and evenness of finishing. |
| **Variable controlled** | Finish uniformity. |
| **Necessary?** | No. |
| **Cheaper alternative** | An upturned plate on a cake stand, or a lazy Susan. |
| **First used in** | [17.3](stage-1/module-17/lesson-03.md) |

### Cake rings and acetate :id=cake-rings

| | |
|---|---|
| **What it does** | Stainless rings (16–20 cm) lined with acetate strips assemble layered cakes and entremets with clean vertical sides. |
| **Why it matters** | The ring holds soft layers while creams set; acetate releases cleanly. |
| **Variable controlled** | Assembly geometry. |
| **Necessary?** | No. |
| **Cheaper alternative** | The ring of a springform pan lined with a double strip of baking paper. |
| **First used in** | [17.3](stage-1/module-17/lesson-03.md) |
