# Templates

Copy these into your own notebook (paper, a spreadsheet, or a notes app). Professional
bakeries run on exactly this kind of paperwork: a standardized formula, a production log and
an experiment record.

| Template | Use it for |
|---|---|
| [Lab notebook / bake log](templates/lab-notebook.md) | Every bake, from 00.1 onward |
| [Standardized recipe](templates/recipe-template.md) | Writing up a formula you own — introduced in 01.4, required in the capstone |
| [Experiment record](templates/experiment-template.md) | Every controlled experiment, and your own experiments later |
