# Standardized recipe template

Every recipe in this course follows this structure. Use it for your own formulas, and in the
[capstone](stage-1/capstone/README.md).

```text
# <ID> · <Product name> — version <n>, <date>
Classification: established technique | source-derived | educational formulation | experimental formulation

Objective             what this recipe is for, and what it must achieve
Expected result       size, weight, appearance, texture, flavour — measurable where possible

Formula
| Ingredient | Baker's % | Grams |
| ...        |           |       |
| Total      |           |       |
Yield: <n> pieces × <g> (dough/batter), expected baked weight <g>
Scaling: flour weight = total required ÷ total % × 100

Equipment             list, including sizes (pan cm, piping tip)
Mise en place         what is weighed, tempered, prepared, preheated — and when

Procedure             numbered steps; every step has a target (temperature, time, or an
                      observable/measurable endpoint)

Critical control points
| CCP | Target | Why it matters |

Common failures       symptom → cause → correction (link the troubleshooting database)
Scientific explanation   why each critical step works
Variables that can be changed
| Variable | Direction | Expected effect |
Experiment suggestions
Storage and shelf life
Sources
Revision history      what changed in each version and why
```
