# Experiment record template

```text
# <ID> · <Title>                       date, operator

Question            one sentence
Hypothesis          "If I <change X>, then <Y> will <direction>, because <mechanism>."
                    Written BEFORE the experiment.

Variables
  Independent       the one thing you change, and its levels (e.g. 60/65/70 %)
  Dependent         what you measure/observe, and how
  Controlled        everything held constant (flour lot, temperatures, times, oven, pan...)

Design              number of variants, replicates, order of baking, labelling, blinding if tasting
Batch               per-variant formula in grams; scale factor used

Procedure           with timing offsets so every variant gets the same treatment

Data                observation table: variant × measurement, plus photos with a ruler

Analysis            what changed, by how much; was the difference larger than batch-to-batch noise?
Conclusion          hypothesis supported / not supported / inconclusive — and why
Next question       what this result makes you want to test next
```

Tips: bake variants on the same oven rack position, label pans before starting, stagger
mixing by a fixed interval (e.g. 10 minutes) so every variant has identical fermentation time,
and photograph cross-sections next to a ruler.
